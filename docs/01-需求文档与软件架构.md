## 一、需求文档

### 1. 项目概述

一款 Windows 11 桌面小工具：用户粘贴视频链接后，软件自动解析链接、下载音频、转换成 MP3、写入歌曲信息（封面/标题/艺术家/专辑），并复制到插入电脑的 U盘 / 内存卡 / MP4 播放器的 `MUSIC` 音乐文件夹中。

产品名暂定「视频转 MP3 助手」，界面风格为**清新、简洁、留白多**。

### 2. 合规边界（硬约束）

- 仅处理**用户主动粘贴、且有权下载/保存**的视频链接。
- **不实现**绕过 DRM、付费墙、登录限制、会员限制、平台禁止下载的任何功能。
- 若目标平台不允许下载（版权限制、会员专享、登录墙等），给出中文提示并**停止**该任务。
- 依赖 yt-dlp 的合法能力，仅用于允许下载的内容；不编写任何绕过检测或破解逻辑。

### 3. 运行环境

| 项 | 值 |
| --- | --- |
| 操作系统 | Windows 11（兼容 Win10） |

### 4. 功能需求

#### F1 链接输入
- 支持单条链接、批量链接（多行粘贴自动提取其中的 http/https 链接）。
- 支持从剪贴板自动识别链接（设置页可开关）。
- 自动去重（同 URL 只保留一条）、过滤无效链接（空行、无协议、格式错误）。
- 入队前校验：URL 格式合法、平台可支持。

#### F2 解析信息
- 显示：标题、作者、时长、封面缩略图、来源站点。
- 解析失败时显示**中文原因**（网络失败 / 链接无效 / 平台限制 / 需登录 / 视频不存在），不崩溃，允许重试。

#### F3 长度调整（用户新增需求）
- **每个任务单独设置**，作用于该任务的 MP3 转换。
- 两种方式，可同时生效：
  - **起止时间截取**：如 `00:00 ~ 03:00`，只转换该片段（适合做铃声/片段）。
  - **最大时长限制**：如「只转前 2 分钟」或「最多 3 分钟」，从起点截取。
- 同时设置时：实际长度 = `min(结束 - 开始, 最大时长)`。
- 时间输入支持 `mm:ss` / `hh:mm:ss`；自动校验：结束 > 开始、不超出视频总时长、片段长度 > 0，非法输入给出中文提示。
- 界面提供快捷选项：整段 / 前 1 分钟 / 前 3 分钟 / 自定义。
- 该参数随任务入库，历史记录可追溯。

#### F4 下载与转换
- 用 yt-dlp 选择**最佳音频流**（`bestaudio`）下载到临时目录。
- ffmpeg 转 MP3：
  - 比特率可选 **128 / 192 / 320 kbps**，默认 **192**。
  - 采样率固定 **44.1kHz**。
  - 可选**响度标准化**（ffmpeg `loudnorm`，默认关闭）。
  - 时长裁剪由 F3 参数决定（`-ss` 起点、`-t` 长度）。
- 写入 ID3v2.3 标签（mutagen，兼容老 MP4 设备）：**封面、标题、艺术家、专辑**。
- 文件名模板可设置，默认 `{artist} - {title}.mp3`。
- 自动清理 Windows 非法字符（`\ / : * ? " < > |`、控制字符、首尾空格/点）。
- 重名自动处理：追加 `(1)`、`(2)` 等后缀。

#### F5 任务队列
- 表格列：封面、标题、作者、时长、状态、进度、操作。
- 支持：开始、暂停、继续、取消、重试、删除。
- 并发数可设置（1–5），**默认 1**，避免卡顿；下载/转码全部在后台线程，**界面不卡死**。
- 状态机见「软件架构」章节。

#### F6 设备导入（U盘 / 内存卡 / MP4）
- 自动检测可移动磁盘（psutil 枚举分区 + 可移动属性判断，或 pywin32 卷信息）。
- 用户选择设备盘符 + 目标文件夹（默认 `MUSIC`，可设置；不存在则自动创建）。
- 转换完成后**自动复制**到设备音乐文件夹；复制后**校验文件大小一致**。
- 可选生成 `.m3u` 播放列表（含本次导入的文件）。
- 可选**安全弹出设备**（Eject，需 pywin32）。
- 设备未插入时：保存到本地输出目录，提示「稍后插入设备可手动导入」。

#### F7 历史记录
- SQLite 保存：链接、标题、作者、输出路径、状态、时间、长度参数（F3）。
- 支持：关键字搜索、重新导出（重新入队）、删除记录。
- 支持「打开文件所在文件夹」（资源管理器定位）。

#### F8 设置页
| 设置项 | 默认值 |
| --- | --- |
| 默认输出目录 | 程序目录下 `output/` |
| MP3 比特率 | 192 kbps |
| 采样率 | 44.1 kHz |
| 命名模板 | `{artist} - {title}.mp3` |
| 并发数 | 1 |
| ffmpeg 路径 | 自动探测（PATH / 常见安装路径），可手动指定 |
| 自动导入设备 | 开 |
| 设备音乐文件夹名 | `MUSIC` |
| 嵌入封面 | 开 |
| 生成 m3u 播放列表 | 关 |
| 安全弹出设备 | 关 |
| 响度标准化 | 关 |
| 剪贴板自动识别 | 开 |

## 二、软件架构

### 1. 分层架构

```
┌──────────────────────────────────────────────────────────┐
│ ① UI 层（PySide6）                                        │
│  主窗口 · 链接输入卡片 · 任务表格 · 设备选择 · 设置对话框    │
│  QSS 清新主题 · 空状态插画 · 信号/槽驱动                    │
└──────────────────────────┬───────────────────────────────┘
                           │ 用户操作 / 信号槽
┌──────────────────────────▼───────────────────────────────┐
│ ② 任务调度层 TaskManager                                  │
│  QThreadPool（并发 N）· 任务状态机 · 进度/状态信号           │
│  暂停/继续/取消控制 · 重试入队                              │
└──────────────────────────┬───────────────────────────────┘
                           │ 分配 Worker（每任务一条流水线）
┌──────────────────────────▼───────────────────────────────┐
│ ③ 服务层（Pipeline 单任务编排）                            │
│  链接提取 → 解析 → 下载 → 转码 → 标签 → 导入                │
│  LinkExtractor | MetadataService | DownloadService        │
│  ConverterService | TagService | DeviceService            │
│  ImportService（复制/校验/m3u/弹出）                        │
└──────────────────────────┬───────────────────────────────┘
                           │ 读写
┌──────────────────────────▼───────────────────────────────┐
│ ④ 数据层                                                  │
│  HistoryDB（SQLite 历史记录）· ConfigStore（JSON 配置）     │
└──────────────────────────────────────────────────────────┘
外部依赖：yt-dlp（下载/解析）· ffmpeg（转码）· mutagen（标签）· psutil / pywin32（设备）
```

### 2. 线程模型

- `TaskManager` 持有 `QThreadPool`，`maxThreadCount = 配置并发数`（默认 1）。
- 每个任务一个 Worker（`QRunnable` + 信号对象）：串行执行 解析 → 下载 → 转码 → 标签 → 导入。
- 状态、进度、日志通过 **Qt 信号**回传 UI 线程，界面永不阻塞。
- 暂停/取消：任务内检查取消标志；对 ffmpeg/yt-dlp 子进程可 `terminate()`，取消后清理临时文件。

### 3. 任务状态机

```
PENDING(等待) ──► PARSING(解析) ──► DOWNLOADING(下载) ──► CONVERTING(转码)
   ▲                │                  │  ▲                  │  ▲
   │                ▼                  ▼  │                  ▼  │
   │            FAILED(失败) ◄────── 任意步骤异常 ◄────────────┤
   │                │ 重试                                        │
   │                └──────────► PENDING                         │
   └──── CANCELED(取消，清理临时文件)   /   PAUSED(暂停) ◄─► 继续
DOWNLOADING 与 CONVERTING 中可 暂停/继续；DONE(完成) 为终态。
```

### 4. 主流程（链接 → MP3 → 设备）

```
粘贴链接 → 提取/去重/校验 → 入队 → 解析元数据 → 下载最佳音频流
→ ffmpeg 裁剪+转 MP3（-ss/-t、比特率、响度可选）
→ mutagen 写 ID3v2.3（封面/标题/艺术家/专辑）
→ 复制到设备 MUSIC/（无设备则存本地 output/）
→ 校验文件大小 → 可选生成 .m3u → 可选安全弹出 → 写入历史库
```

### 5. 数据库设计（SQLite 单表 `tasks`）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | INTEGER PK | 自增主键 |
| url | TEXT | 视频链接 |
| title / artist / album | TEXT | 标题 / 艺术家 / 专辑 |
| duration | REAL | 视频时长（秒） |
| cover_path | TEXT | 封面本地路径 |
| start_time / end_time / max_duration | TEXT | F3 长度参数（mm:ss / 空） |
| status | TEXT | pending / parsing / downloading / converting / tagging / importing / done / failed / canceled / paused |
| progress | INTEGER | 0–100 |
| output_path | TEXT | 最终 MP3 路径 |
| device_path | TEXT | 设备复制路径（如 F:\MUSIC\xxx.mp3） |
| error_msg | TEXT | 失败原因（中文） |
| created_at / updated_at | TEXT | 创建 / 更新时间 |

> 设计说明：任务与历史记录**共用一张表**，任务创建即入库，状态实时更新；「历史记录」页面即该表的查询视图，重新导出 = 改状态重新入队。

### 6. 配置 JSON 结构（`config.json`）

```json

  "bitrate_kbps": 192,
  "sample_rate": 44100,
  "name_template": "{artist} - {title}.mp3",

  "device_music_dir": "MUSIC",
  "embed_cover": true,
  "gen_playlist": false,
  "safe_eject": false,
  "normalize_loudness": false,
  "clipboard_autodetect": true
}
```
